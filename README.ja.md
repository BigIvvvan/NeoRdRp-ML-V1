# NeoRdRp-ML V1 の結果確認

保存済みの V1 候補区間を参照区間およびタンパク質全長のベースラインと比較するオフラインツールです。同梱デモには評価済みの 1 件の座標を収録しています。比較指標はコマンド実行時に計算されます。入力形式は JSON です。

[English](README.md)

## インストールと実行

Python 3.11 以上で、リポジトリのルートから次のコマンドを実行します。

```sh
python -m pip install .
neordrp-ml-v1-review
```

ビルド済みの wheel をインストールした場合も同じコマンドを使えます。実行時に GPU やネットワーク接続は不要です。

## 1 件のデモ

入力長は 1,699 残基、参照区間は 1,405–1,694、保存済みの候補区間は 14–1,676 です。開始点と終了点の符号付き誤差はそれぞれ −1,391 残基と −18 残基です。IoU は候補区間で約 0.1618、全長ベースラインで約 0.1707 です。参照区間は構造モジュールの外包区間です。座標は 1 始まりで両端を含みます。

別の保存済み区間は `neordrp-ml-v1-review path/to/record.json` で評価できます。必須フィールドは `schema_version`（現在は `1`）、`input_length`、`reference_interval`、`predicted_interval` です。区間は `[1, input_length]` の範囲内の整数 2 個で指定します。同梱 JSON には固定チェックポイントの SHA-256 が記録されています。
